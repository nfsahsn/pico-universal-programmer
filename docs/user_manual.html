3. Target 1: WCH CH32V003 (1-Wire SWIO)

The CH32V003 uses WCH's proprietary single-wire debug interface on pin PD1. This is the only way to flash a blank CH32V003 (it has no BOOT0 pin and no built-in UART bootloader).

Wiring Table

Pico PinPico FunctionCH32V003 TargetNotes
Pin 34GP28PD1 (SWIO)Single-wire data line
—1kΩ ResistorBetween 3.3V and PD1Mandatory pull-up resistor
Pin 363V3 OUTVDD (3.3V)Powers the target chip
Pin 38GNDGNDCommon ground
⚠ CRITICAL: PULL-UP RESISTOR REQUIRED
The 1kΩ pull-up resistor between 3.3V and the PD1 pin is absolutely mandatory. Without it, the 1-wire protocol cannot pull the signal high fast enough and programming will fail.

Arduino IDE Steps

  1. Tap the Mode Button (GP15) until the Blue LED is on (or the onboard LED blinks 3 times).
  2. In Arduino IDE: Tools > Board > CH32V EVT Boards → CH32V003 EVT
  3. Tools > Port → Select your Pico's COM port
  4. Tools > Programmer → Pico Universal: PicoRVD (CH32V003 1-Wire SWIO)
  5. Press Ctrl + Shift + U (Upload Using Programmer)

Arduino IDE Steps

  1. Set the Pico to Mode 1 (Green LED / 1 Blink).
  2. Tools > Board > STM32 boards groups → Select your board (e.g. Generic STM32F1 series)
  3. Tools > Upload method → OpenOCD
  4. Tools > Programmer → Pico Universal: CMSIS-DAP (SWD)
  5. Press Ctrl + Shift + U

7. Serial Monitor (UART) Debugging

The Pico programmer provides a built-in USB-to-UART serial bridge over the same USB cable, so you can view your target board's Serial.println() output without an additional FTDI adapter.

Pico Programmer PinFunctionTarget Pin
Pin 1 (GP0)UART TX (Pico sends data)Target RX
Pin 2 (GP1)UART RX (Pico receives data)Target TX
Pin 8 (GND)GND (Required)Target GND

In Arduino IDE, open Tools > Serial Monitor (Ctrl + Shift + M) to see live output from your target board in real time.

8. Arduino IDE One-Click Setup

Step 1: Install Board Packages

In Arduino IDE, go to File > Preferences and add these URLs to the Additional Boards Manager URLs field (comma-separated):

Board FamilyURL
WCH CH32Vhttps://github.com/openwch/board_manager_files/raw/main/package_ch32v_index.json
STM32https://github.com/stm32duino/BoardManagerFiles/raw/main/package_stmicroelectronics_index.json
RP2040https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json
ESP32https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

Then go to Tools > Board > Boards Manager and install the cores you need.

Step 2: Run the Installer Script

Double-click the installer script located in your project folder:

arduino\install_arduino_support.bat

It auto-detects your installed Arduino cores and installs the custom programmer recipes. Restart Arduino IDE after running.

10. Electrical Safety Rules

⚠ VOLTAGE WARNING (3.3V LOGIC)
The Raspberry Pi Pico GPIO pins are strictly 3.3V and are NOT 5V tolerant. If your target board runs at 5V (e.g., Arduino Uno/Nano), you must use a bidirectional logic level shifter on all signal lines. Feeding 5V into the Pico will permanently destroy the RP2040.
⚠ COMMON GROUND
Always connect GND between the Pico and your target board, even if both boards are powered by separate USB ports. Without a common ground reference, communication will be unreliable and you risk hardware damage.
⚠ CH32V003 PULL-UP RESISTOR
Never omit the 1kΩ pull-up resistor on the CH32V003 PD1 line. Without it, the single-wire protocol cannot operate and the chip will not respond.
